> 日期: 2026-04-28 | 对比对象: 券商研报标准/CFA框架/国际投行规范 vs 我们的 fundamentals-analyst
> 测试股票: 300033.SZ 同花顺 | 基本面评分: 65分 bullish

## 一、专业研报的标准结构

### 券商研报典型框架（中信/海通/国泰君安/中金标准）

```
1. 投资要点（1-2页）
   ├── 核心投资逻辑
   ├── 与市场一致预期的差异
   ├── 关键假设与催化剂（带时间线）
   └── 盈利预测与目标价

2. 公司概况（2-3页）
   ├── 股权结构与实际控制人
   ├── 主营业务结构（营收/利润分部占比）
   ├── 历史沿革（上市、重大资产重组）
   └── 管理层背景与激励机制

3. 行业分析（3-5页）
   ├── 行业空间与增速（TAM/SAM/SOM）
   ├── 竞争格局（CR3/CR5、市占率）
   ├── 行业生命周期判断
   ├── 政策环境与监管趋势
   └── 产业链分析（上下游议价能力）

4. 公司竞争力分析（3-5页）
   ├── 核心竞争优势（护城河分析）
   ├── 与竞争对手的多维度对标
   └── 竞争优势的可持续性

5. 业务分析（5-8页）
   ├── 分业务线收入与利润拆解
   ├── 核心产品/服务分析
   ├── 客户结构（前五大客户占比）
   ├── 产能分析与利用率
   └── 新业务/新增长点

6. 财务分析（5-8页）
   ├── 三表分析（利润表/资产负债表/现金流量表）
   ├── 盈利/营运/偿债/成长四维分析
   ├── 杜邦分析（5因素分解）
   └── 关键指标与同行对比

7. 盈利预测（3-5页）
   ├── 核心假设（分业务线）
   ├── 分部预测
   ├── 三年盈利预测表
   └── 敏感性分析（乐观/基础/悲观）

8. 估值与投资建议（3-5页）
   ├── 估值方法选择与理由
   ├── 可比公司估值对比
   ├── 目标价推导
   └── 投资评级与风险收益比

9. 风险提示（1-2页）
   └── 关键风险因素 + 量化影响

附录: 三表预测、假设汇总、可比公司估值表
```

### CFA 专业估值四步法

```
第一步: 了解业务
  → 波特五力模型 + 竞争定位 + 公司治理

第二步: 预测业绩
  → 财务建模 + 关键假设 + 情景分析（Bull/Base/Bear）

第三步: 选择估值方法
  → 绝对估值(DDM/DCF/FCFF) + 相对估值(PE/PB/EV/EBITDA)
  → 根据行业和生命周期选择

第四步: 得出结论
  → 内在价值 vs 市场价格 + 安全边际
```

## 三、逐项差距分析（按严重程度排序）

### 差距1: 缺少"盈利预测" — 我们最大的结构性缺失

**专业标准**: 券商研报的核心不是"分析过去"，而是"预测未来"。专业研报必须有:
- 分业务线的3年盈利预测表（收入、毛利率、费用率、净利润）
- 核心假设清单（如"假设2026年增值电信服务收入增速30%"）
- 情景分析: Bull（乐观）/ Base（基础）/ Bear（悲观）三种情景
- 敏感性分析: 关键假设变动对目标价的影响

**我们现状**: 完全没有盈利预测。我们的分析是"回顾式"的——只看过去4个季度的数据。

**影响**: 没有盈利预测 = 没有目标价 = 投资者不知道"该在什么价位买/卖"。

**修复难度**: ★★★★☆ — 需要LLM做预测，且预测准确性难保证

**优先级**: **P1 — 专业研报的灵魂**

---

### 差距2: 缺少"估值方法选择"和"可比公司对标"

**专业标准**:
- 根据公司类型选择估值方法（软件用PE/PEG，银行用PB，周期用EV/EBITDA）
- 找3-5家可比公司，列出估值倍数对比表
- 推导目标价（而非只说"PE在历史7.4%分位"）

**我们现状**:
- 只有PE/PB百分位，没有可比公司对标
- PE百分位7.4%（低估）和PB百分位99.4%（高估）矛盾，但没有解释为什么
- 没有目标价推导

**影响**: 投资者看到"PE低估"但不知道"同行是不是更低"

**修复方案**: 新增 `get_peers` 工具，获取同行业公司估值数据进行对标

**优先级**: **P1 — 估值的参考基准缺失**

---

### 差距3: 缺少"行业分析"和"竞争格局"

**专业标准**: 
- 行业空间（TAM/SAM/SOM）
- 竞争格局（CR3/CR5、市占率）
- 行业生命周期判断（导入期/成长期/成熟期/衰退期）
- 政策环境分析

**我们现状**: 只有 get_index 返回的行业指数涨跌幅，没有行业分析。

**影响**: 同花顺在"金融信息服务"赛道的市占率是多少？主要竞争对手东方财富、指南针的ROE是多少？都不知道。

**修复方案**: 
- 方案A: 在 skill 中让 LLM 基于已有数据做定性行业判断
- 方案B: 新增 `get_industry_data` 工具获取行业统计

**优先级**: **P1 — 没有行业背景的分析是空中楼阁**

---

### 差距4: 缺少"催化剂"和"时间线"

**专业标准**:
- 列出未来6-12个月的关键催化剂事件
- 每个催化剂有明确时间线和预期影响
- 如: "2026年6月新产品发布 → 预计贡献营收3亿"

**我们现状**: 完全没有。key_observations 只有对过去数据的描述。

**影响**: 投资者不知道"什么时候该关注这只股票"

**修复难度**: ★★★☆☆ — 需要 LLM 基于行业知识推断

**优先级**: **P2 — 投资时机的关键**

---

### 差距5: 缺少"情景分析"

**专业标准**: Bull/Base/Bear 三种情景 + 概率加权
```
乐观情景（30%）: 营收增速50% → 净利润30亿 → 目标价180元
基础情景（50%）: 营收增速35% → 净利润25亿 → 目标价150元
悲观情景（20%）: 营收增速20% → 净利润20亿 → 目标价120元
加权目标价 = 180×0.3 + 150×0.5 + 120×0.2 = 151元
```

**我们现状**: 只有一个 score=65，没有概率分布。

**修复难度**: ★★★☆☆

**优先级**: **P2 — 提升投资决策质量**

---

### 差距6: 评分体系 vs 综合评级体系

**专业标准**:
- 买入/增持/中性/减持/卖出（5级评级）
- 目标价 + 潜在涨幅/跌幅
- 风险收益比
- 评级变更记录

**我们现状**:
- bullish/bearish/neutral（3级，太粗）
- 0-100分数
- 没有目标价

**修复方案**: 升级为5级评级 + 增加目标价推导

**优先级**: **P2 — 评级颗粒度太粗**

---

### 差距7: 缺少"管理层分析"

**专业标准**:
- 实际控制人背景和持股
- 管理层激励计划（期权、限制性股票）
- 大股东增减持行为
- 股权质押比例

**我们现状**: 完全没有。get_institutional 只返回机构数据。

**修复方案**: 新增高管增减持、股权质押数据（Tushare有接口）

**优先级**: **P2 — A股特有关注点**

---

### 差距8: 缺少"分红分析"

**专业标准**:
- 股息率（当前/3年平均）
- 分红率（分红/净利润）
- 分红政策（是否稳定）
- 和同行的分红对比

**我们现状**: 完全没有分红数据。

**修复方案**: Tushare有 `dividend` 接口

**优先级**: **P2 — 价值投资者必看**

---

### 差距9: quality.py 检查了基本面报告的技术指标（BUG）

**现象**: 基本面报告验证出现 "Missing price levels: ['strong_support', 'weak_support', 'weak_resistance', 'strong_resistance']" 警告。

**根因**: quality.py 第7-10步的支撑/压力/止损/风险收益检查不区分 schema_type，对基本面报告也运行了技术指标的检查逻辑。

**修复**: 在第7-10步前加 `if schema_type == "technical":` 条件判断

**优先级**: **P1 — Bug修复**

---

### 差距10: valuation_scoring 二元对立问题

**现象**: 同花顺 PE百分位=7.4%得10分，PB百分位=99.4%得0分。轻资产公司PB天然极高，0分不合理。

**专业标准**: 对轻资产公司，PB权重应降低或改为PS。

**修复方案**: 在评分时识别行业类型，对轻资产行业降低PB权重

**优先级**: **P2 — 评分准确性**

## 五、一句话结论

**我们的报告 = 一份高质量的"财务体检报告"**
**专业研报 = 一份"从行业到公司到估值到买卖点的完整投资方案"**

差距不在于"数据计算准不准"（我们算得够准），而在于"分析够不够深、有没有前瞻性、能不能指导投资决策"。

最关键的三件事：
1. **盈利预测** — 从"回顾过去"升级为"预测未来"
2. **可比公司** — 从"自说自话"升级为"有参照系"
3. **行业分析** — 从"只看个股"升级为"理解赛道"

这三件事做好后，报告质量会有质的飞跃——从"分析师助手"升级为"投资决策工具"。
